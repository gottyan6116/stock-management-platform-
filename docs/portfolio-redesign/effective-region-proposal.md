# 実質地域（look-through）配分の提案（調査・提案のみ・未実装）

## 何が難しいか

投資信託は「全世界株式」のような名前でも、中身は国・地域に分かれる。株式は本社所在地（または主要売上地域）で、ファンドは構成比データで按分する必要がある。**この構成比は一般に公開データだが、ファンドごとに取得経路が異なり、現状のコードベースには存在しない。**

## 候補データソース（いずれも未検証。採用前に取得可否と規約を確認）

| 案 | 内容 | 長所 | 懸念 |
|---|---|---|---|
| A. 月次運用報告書（目論見書補完書面）の手入力 | 各ファンドの「国別構成比」を年数回、画面から入力 | 正確・規約問題なし・追加インフラ不要 | 保有8本分を自分で更新する手間 |
| B. 運用会社の公開ページ／CSV | 例: 各運用会社サイトの構成比 | 自動化の余地 | サイトごとに形式が違い、規約・変更耐性が不明 |
| C. 市場データAPI（Yahoo等）の fund holdings / country weightings | 米国上場ETFでは取得できる場合がある | 自動 | 日本の投信は対象外の可能性が高い。取得可否は未確認 |
| D. 代表ファンドの近似（例: オルカン=MSCI ACWI の国別ウェイト） | インデックスの公表ウェイトを流用 | 少ない入力で足りる | 近似であることの明記が必須 |

## 推奨

**A + D の併用（手入力を基本、指数連動ファンドは指数ウェイトを流用）。**

- `fund_region_weights(instrument_id, as_of, region, weight)` のような小さなテーブルを追加し、合計100%になることを検証する。
- 値が無いファンドは「実質地域: 未設定」として配分から分けて表示（推定で埋めない）。
- 画面には「出典と基準日」を必ず1行で出す。
- 個別株は `instruments` の国コードで地域を決める（日本株=日本、米国株=米国）。

## 決めてほしいこと

1. 地域の粒度: 日本 / 米国 / 先進国(除く日米) / 新興国 の4分類でよいか。
2. 保有8本のうち、まず入力したい上位ファンド（評価額の大きい順に着手を提案）。
